Legal Metrology Compliance Pipeline

Offline-first Android app · PaddleOCR + OpenCV · ArUco-calibrated font measurement  ·  Legal Metrology (Packaged Commodities) Rules 2011

Notes on this flow

  • SHA-256 is computed on the original image before CLAHE/deskew — preprocessing must never touch what gets hashed.
  • Rule engine currently uses regex; YOLOv8-nano (layout) and MobileNetV3 (font style) are planned improvements.
  • Font size = bounding-box height in px × ArUco mm/px ratio; threshold 1.00 mm.
